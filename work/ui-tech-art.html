UI and technical art

Voxie Tactics and Hyperflora2022 to 2026UGUI · UI ToolkitShader Graph and HLSLEditor toolingiOS and Android

The engineering side of art and UI on two live Unity games. On Voxie Tactics, a free-to-play tactics game on Windows, iOS, and Android, that meant the 2025 UI overhaul in UGUI, the mobile UI port, the avatar shaders, and the asset tooling behind them. On Hyperflora, a top-down action roguelike on Steam, it means the UI Toolkit design system, custom URP renderer features, and the MagicaVoxel content pipeline.

UI implementation

Hyperflora's UI is a gamepad-first UI Toolkit design system across 20 screens. Every terminal shares one frame and one focus ring, and input prompts swap between gamepad and keyboard glyphs at runtime. EditMode tests fail when a screen breaks the focus-ring or input-prompt standard.

On Voxie Tactics, led the 2025 UI overhaul end to end in UGUI, restyling every battle and menu screen. Built a view framework with playground scenes so each view could be developed in isolation, without booting login, matchmaking, and a server. Added UIFX effects, button animation, and click audio, and shipped the UI in English, French, and Brazilian Portuguese with an auto-localizing text component. Also built the in-game store UI, with dynamic categories, product cards, WebP thumbnails, and in-app purchases on mobile and PC.

Shaders and rendering

Occlusion reveal. The player stands behind the pillar and reads through it as a tinted silhouette.

Occlusion reveal (Hyperflora)

A custom URP renderer feature. When a wall or pillar hides a character, the character is redrawn on top as a tinted silhouette inside a soft circle, and no wall material changes. An obstacles-only depth prepass gates the redraw, and per-pixel character depth keeps the silhouette from flickering at the edges.

Light trail (Hyperflora)

A second renderer feature that accumulates and blurs emissive pixels into a motion smear, composited over the frame. A palette LUT generator bakes the game's Resurrect 64 palette into a lookup texture.

Avatar shaders (Voxie Tactics)

Wrote the avatar color-replacement shader in Shader Graph, which recolors skin, hair, eyes, and secondary colors across more than 2,100 modular part assets, plus the current-turn outline and ghost and invisibility shaders driven by character traits. Built the ability and status-effect VFX on the Particle System, and turned on GPU instancing across every battle map tile material.

Editor tooling and asset pipeline

  1. MagicaVoxel modelRooms and props are authored as .vox files.
  2. AssetPostprocessorImport splits each model with its per-model split settings.
  3. Per-tile prefabsOne prefab per tile, ready for a tileset.
  4. TesseraTiles and constraints assemble the rooms.
  5. Procedural roomsEvery run builds new floors from the same kit.

Hyperflora's rooms start as MagicaVoxel models, and AssetPostprocessors turn them into per-tile prefabs on import. Editor tooling covers tilesets, palettes, and mineral budgets, plus an orthographic render studio and a dungeon overview capture tool.

On Voxie Tactics, brought Addressables into the project and moved avatar parts and battle maps onto addressable groups, with a custom window for finding any asset's address. Built an avatar part browser and creator, a map editor with placement validation, a rewards editor, and a batch capture tool that records transparent 256 by 256 icons for the UI. A scripted build step produces the Windows, iOS, and Android players with versioning.

Mobile

Brought Voxie Tactics from PC to iOS and Android. Battle and menu UI were adapted for touch, safe areas, and orientation, and a canvas matcher switches CanvasScaler matching by screen aspect so layouts hold on phones and tablets. Mobile-only quality settings and frame-rate targets apply on device, and builds ship through fastlane to TestFlight and the Play Console.

Earlier mobile and casino work includes a mobile slot-game platform at WGames, where art was integrated into the game templates and the game-loading system rebuilt, and a multiplayer poker console for live casinos at Cloud Street Gaming, with the art pipeline, post-processing, and a UI and UX overhaul. Before that, five years at Timeplay shipping branded games played on audiences' phones on fixed campaign deadlines.

Standards and validation

On Voxie Tactics, Odin Validator has run in CI since 2022, and any validation error or warning fails the build. On Hyperflora, EditMode test suites enforce the UI, input, economy, and save standards, so a broken focus ring or a missing input prompt is caught by a test instead of by a player.
