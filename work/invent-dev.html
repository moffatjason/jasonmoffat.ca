VR architectural configurator

Invent Dev2019, contractLead developerVR application · HTC Vive and Oculus

A VR application for customizing architectural designs: change home layouts, place furniture from a tagged library with filters, and see it rendered at high fidelity. Architected the application, designed and implemented the UI and UX for layout changes and furniture placement, built the furniture library and its filtering, implemented the high-definition rendering paths, and designed the system for backend integration.
