A gamepad-first UI Toolkit design system across 20 screens. Every terminal shares one frame and one focus ring, input prompts swap between gamepad and keyboard glyphs at runtime, and EditMode tests fail when a screen breaks the focus-ring or input-prompt standard.

Technical art

Shaders and rendering

Occlusion reveal. A custom URP renderer feature. When a wall or pillar hides a character, the character is redrawn on top as a tinted silhouette inside a soft circle, and no wall material changes. An obstacles-only depth prepass gates the redraw, and per-pixel character depth keeps the silhouette from flickering at the edges.

Light trail. A second renderer feature that accumulates and blurs emissive pixels into a motion smear, composited over the frame.

Avatar shaders (Voxie Tactics). A Shader Graph color-replacement shader recolors skin, hair, eyes, and secondary colors across more than 2,100 modular part assets. Also the current-turn outline and the ghost and invisibility shaders driven by character traits.

Asset pipeline and editor tooling

  1. MagicaVoxel modelRooms and props are authored as .vox files.
  2. AssetPostprocessorImport splits each model with its per-model split settings.
  3. Per-tile prefabsOne prefab per tile, ready for a tileset.
  4. TesseraTiles and constraints assemble the rooms.
  5. Procedural roomsEvery run builds new floors from the same kit.

Hyperflora's rooms start as MagicaVoxel models, and AssetPostprocessors turn them into per-tile prefabs on import. Editor tooling covers tilesets, palettes, and mineral budgets, plus an orthographic render studio, a palette LUT generator, and a dungeon overview capture tool.

On Voxie Tactics, the battle map pipeline turns legacy map data into template-built, GPU-instanced tile maps. Also brought Addressables into the project for avatar parts and battle maps, with a custom window for finding any asset's address, and built a map editor with placement validation and a batch capture tool that records transparent icons for the UI.
